# Job agent workspace (Antigravity)

1. Open this folder as a workspace in Antigravity.
2. Edit profile/targets.md and profile/achievements.md.
3. Rules live in .agents/rules, skills in .agents/skills, slash commands in .agents/workflows.
   (If your Antigravity version uses .agent singular, rename the folder.)
4. Daily: run /daily-scan. For a role: /apply <link>. Before interviews: /prep <company>. Sundays: /weekly-review.
5. You review and send everything yourself.
