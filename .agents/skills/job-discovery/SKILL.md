# Job discovery

1. Read profile/targets.md (titles, locations, companies, comp, sponsorship rules).
2. For each target company and each location group, search public career pages and web search for roles posted in the last 14 days. Run separate searches per company; do not combine.
3. Skip roles clearly below senior level, outside targets, or already in tracker.csv.
4. For each candidate role open the actual posting and extract: title, location, posted date, comp, sponsorship/relocation wording, team, 3 key requirements.
5. Append qualifying roles to jobs/shortlist.md as a table, newest first. Mark unverified fields as UNVERIFIED.
6. Finish with a summary: how many found, top 5 by likely fit, anything that looks like a repost or ghost job (open 60+ days).
Do not apply. Do not message anyone.
